Smart Academic Search Engine

A notebook-based Python prototype for searching a sample academic document collection. Uses text preprocessing, a positional inverted index, TF-IDF weighting and cosine-similarity ranking.

Switchable phrase-aware scoring and WordNet synonym expansion make it possible to compare search results before and after each improvement.

  • Python
  • NLTK
  • TF-IDF
  • Cosine similarity

Notebook prototype. Not currently hosted online.
