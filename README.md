# Rahma Hesham | Personal portfolio

A responsive portfolio website built with plain HTML and CSS. No framework, build step, JavaScript dependency or tracking.

## Files

- `index.html`: page structure and content
- `styles.css`: layout, colours, responsive breakpoints and focus states

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Edit the site

Update the project descriptions, contact details and links in `index.html`. Adjust the colour variables at the top of `styles.css` to change the theme. Decorative project illustrations are CSS-only, not screenshots or charts of measured results.

## Hosting

The site is designed for GitHub Pages, serving the repository's root directory from the `main` branch.
